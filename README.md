# HMR Math

The mathematics of the Holistic Model of Reality (HMR). The readable version lives at the HMR source pages; this repository holds the versions, the axioms and theorems in plain text, and the scripts that check them.

## Versions

| Version | Date | Status |
|---|---|---|
| V1 | 2026-11-20 | Live on the site. One relation ("builds on"), never circular, finitely many thoughts between any two; the attachment rule; the K-parent growth rule |
| V2 | in progress | Extends the model to a mechanics of thinking: truth, ignorance, mistake, and lie; ideas and their size; emotion; what an internal contradiction does to an idea. Theorems are being checked by brute force on all small patterns before publication |

## Labels we use

Established mathematics, HMR as written (V1), NEW (a definition proposed for V2), theorem (proved here), conjecture (not proved). Nothing is published as a theorem until its proof is written out and, where possible, checked by script in `checks/`.

## Contributing

Corrections and counterexamples are welcome as issues. We would rather know where we are wrong.
